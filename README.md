# 智能开票助手 (Smart Invoice Assistant)

> 基于 WebView2 的电商平台发票信息抓取与国家税务总局开票系统自动填单工具

## 📖 项目简介

**智能开票助手**是一个运行在 Windows 平台的桌面工具，专为电商卖家（淘宝 / 天猫 / 1688）设计，用来打通 **"电商订单 → 发票信息 → 国税开票系统"** 之间的数据流。

程序内嵌两个 WebView2 浏览器：左侧是**税务开票系统**，右侧是**淘宝 / 天猫 / 1688 商家后台**。通过拦截电商页面的接口数据、解析订单详情，并自动将发票抬头、税号、金额、明细等信息填入税务系统的开票表单，从而把原本 3～5 分钟的手动开票流程压缩到几秒之内完成。

## ✨ 主要功能

### 🛒 电商端（右侧 WebView）
- **双平台支持**：可在 `淘宝 / 天猫` 和 `1688` 之间一键切换（Button23）
- **登录状态持久化**：自动保存 / 恢复 Cookies，无需每次手动登录
- **订单信息自动拦截**：通过 `WebResourceResponseReceived` 拦截淘宝 / 天猫 / 1688 的订单详情接口，直接解析：
  - 实付款金额
  - 付款时间
  - 商品标题 / 商家编码 / 规格 / 数量
  - 发票抬头、税号、开户银行、账号、电话、地址（1688 模式）
- **自动唤起旺旺**：点击订单的「旺旺在线」按钮
- **智能商品编码获取**：通过 MD5 签名算法调用淘宝后台商品接口，从商品描述中提取商家编码

### 🧾 税务端（左侧 WebView）
- **自动登录填充**：按账号索引读取本地配置，自动填充税号 / 手机号 / 密码并提交
- **智能填单**：
  - 自动填写发票抬头、购方税号
  - 自动填写企业地址、电话、开户银行、开户账号
  - 自动勾选「是否开票给自然人」并关闭提示弹窗
  - 自动填写商品明细（品名、规格、数量、金额）
- **税号匹配验证**：模拟点击税号输入框，自动完成模糊匹配选择
- **二维码交付**：自动打开二维码弹窗、提取 PDF 下载 URL 并静默下载

### 🤖 智能解析（AI）
- 集成 **智谱 AI（GLM-4-flash）** 免费模型
- 支持将任意格式的**粘贴文本**（微信 / QQ 聊天记录、OCR 结果等）智能提取为标准开票字段：发票抬头、税号、地址、电话、开户行、账号、邮箱

### 📥 自动下载与重命名
- 拦截 WebView2 下载事件，强制保存到指定目录
- 根据发票 PDF 内容自动识别购买方名称，并将 PDF 文件名中的客户名替换为规范名称
- 支持"一键开票 → 下载 PDF → 回填发票信息"的完整流水线

### ⌨️ 快捷键

| 按键 | 功能 |
|------|------|
| `F1` | 智能填入详情（订单号抓取 + 自动填单） |
| `F2` | 清除表单 & 返回「发票开具」页 |
| `F3` | 一键下载 + 开票（组合流程） |
| `F4` | 税号验证 + 企业信息填充 |
| `↑ / ↓` | 调整增行数 |

> 快捷键**仅在主窗口未最小化时生效**，且会拦截默认的浏览器行为。

### 🗂 系统托盘
- 关闭窗口不退出，最小化到系统托盘
- 双击托盘图标还原窗口，右键菜单支持「显示 / 退出」

## 🚀 安装与运行

1. **安装 WebView2 Runtime**（若系统未预装）。
2. 下载 / 编译本项目，确保 `WebView2Loader.dll` 与主程序位于同一目录（程序首次运行会自动从嵌入资源中释放该 DLL）。
3. 双击运行 `Form1.exe`。
4. 首次启动后：
   - 在顶部下拉框中**选择当前操作账号**（对应本地配置的多套账号 / 企业）
   - 点击**「保存登录信息」** 填写电商账号与税务账号
   - 通过**「设置」**填写 `ZhipuApiKey`（智谱 AI 密钥，可免费申请）
   - 通过**「选择下载路径」**指定发票 PDF 保存目录

## 🧭 使用流程

### 基础自动开票
1. 在右侧浏览器登录电商后台，进入含发票按钮的订单详情页
2. 在左侧浏览器登录税务开票系统
3. 点击左上角 **【智能填入详情】(F1)**：
   - 程序自动抓取当前页订单号
   - 打开隐藏 WebView 拦截订单接口数据
   - 解析金额、商品、数量、抬头、税号等
   - 自动填写税务系统的所有字段
4. 点击 **【确定开票】(F2)** 提交
5. 点击 **【二维码交付】(F3 / F1 组合键)**：程序打开二维码弹窗并获取 PDF URL，静默下载并按客户名重命名 PDF
6. 点击 **【上传 PDF 到税局】**：程序打开上传弹窗并自动注入 PDF 路径，等待解析完成后点击「完成开票」

### 手动输入开票
- 在下方文本框中粘贴微信 / QQ 里的开票信息 → 点击 **「智能解析」**（AI 自动提取字段）
- 或直接点击 **「填充登录信息」** 完成税务系统登录

## ⚙️ 配置说明

配置文件 `config.json` 与程序同目录，主要字段：

| 字段 | 说明 |
|------|------|
| `TaoBaoCookies` / `B2BCookies` / `TaxCookies` | 三套平台的登录 Cookie（自动维护，无需手改） |
| `Account1~5` / `Password1~5` | 淘宝 / 1688 账号（最多 5 个） |
| `TaxNumber1~5` / `Phone1~5` / `Passwordx1~5` | 税务系统账号（最多 5 个） |
| `Company1~4` / `Shop1~4` | 本地企业名与店铺名配对，用于**平台切换时校验** |
| `Keywords1~7` / `Spec1~7` | 商品标题关键词 → 开票品名映射规则 |
| `SelectedPath` | PDF 下载目录 |
| `Region` | 税局站点所在省份 |
| `IsB2BMode` | 当前是否 1688 模式（持久化） |
| `SaveDrawer` | 是否勾选「开票给自然人」 |
| `ConditionList` / `TriggerUnit` / `Payee` / `Reviewer` | 触发单位换算的条件品名、默认收款人、复核人 |

## 🔐 隐私与安全说明

- 所有账号、密码、Cookie **仅存储于本地 `config.json`**，不会上传任何服务器
- WebView2 的浏览器数据存储于程序目录下的 `WebView2Data/` 文件夹
- 智谱 AI 仅在「手动粘贴智能解析」时调用，字段内容会发送至智谱 API，请**不要**粘贴含敏感信息的文本
- 下载的发票 PDF 会保存在你指定的本地目录，不会外传

## ❓ 常见问题

**Q1：点击「智能填入详情」提示"未获取订单号"？**
> 请确认当前停留在**订单详情页**（URL 含 `trade_order_detail` 或 `trade-order-detail`），且订单详情已完全加载。

**Q2：税局页面字段填不进去？**
> 税局前端可能升级了 DOM 结构，需检查 `Form1.vb` 中各 `fillSingleField` 调用中的选择器（如 `.t-form-item__gmfnsrsbh`）是否仍匹配。

**Q3：WebView2 初始化失败？**
> 请确认已安装 **WebView2 Runtime**，且程序目录下的 `WebView2Loader.dll` 未被杀毒软件拦截。

**Q4：AI 解析返回字段为空？**
> 请检查「设置」中是否填写 `ZhipuApiKey`，并在[智谱开放平台](https://open.bigmodel.cn/)确认该 Key 有 `glm-4-flash` 的调用额度。

**Q5：为什么快捷键 F1-F4 有时无响应？**
> 快捷键仅在主窗口**未最小化**且对应按钮 **Enabled + Visible** 时触发（设计如此，避免在后台误操作税局）。
